# MATHORIA 數域魔法學院 — G9 數學冒險地圖（MVP 1）

依康軒九上、九下單元設計的遊戲化課程入口：八大據點、角色四階進化、XP 與徽章、迷思魔王戰。純前端，可直接放上 GitHub Pages。

## 部署
1. 把整個資料夾上傳到 GitHub repo（例如 `mathoria`），開啟 GitHub Pages（Deploy from branch → main / root）。
2. 網址會是 `https://<帳號>.github.io/mathoria/`。
3. 先改 `js/courses.js` 的 `approvalSecret`，換成只有你知道的字串。

## 檔案
- `index.html` 學生主城（建角 → 地圖 → 據點 → 任務回報 → 魔王戰）
- `teacher.html` 教師後台：全班進度、最新動態、關卡預覽
- `js/questions.js` 魔王戰題庫（每站 10 題，可直接改）；`js/story.js` 人物對話
- `js/courses.js` **所有課程設定都在這裡**：據點、章節、任務、連結、XP、封印開關
- `js/app.js` 遊戲邏輯；`js/audio.js` 背景音樂與音效（Web Audio 即時合成，無音樂檔）；`css/style.css` 樣式
- `assets/` 角色、表情、寵物、徽章、地圖

## 老師常用的三件事
- 開放據點：把該據點的 `sealed: true` 改成 `false`。
- 掛新課程網頁：在該單元填 `url` 與 `urlLabel`。
- 魔王戰是答題戰鬥：答對攻擊、答錯被反擊（失去 3 顆心重來），打贏就擊敗魔王並寫入試算表。

## 連接 Google 試算表（雲端模式）

不設定也能用（離線模式：進度只存在學生瀏覽器）。設定後：任務回報與魔王擊破寫進試算表、核可碼改由後端驗證、學生換裝置自動還原、教師後台看全班進度。

1. 開一個新的 Google 試算表，命名例如「MATHORIA 學生進度」。
2. 選單「擴充功能 → Apps Script」，把 `apps-script/Code.gs` 的內容整份貼上，存檔。
3. 上方函式選單選 `setup`，按「執行」，依提示授權。試算表會多出「事件紀錄」「學生名冊」兩張工作表。
4. 左側齒輪「專案設定 → 指令碼屬性」，修改兩個值：
   - `TEACHER_KEY`：教師後台登入用的金鑰
   - `APPROVAL_SECRET`：產生核可碼用的密語（設定後不要再改，改了舊的核可碼會失效）
5. 右上「部署 → 新增部署作業」，類型選「網頁應用程式」：執行身分「我」、存取權「任何人」，按部署，複製網址（結尾是 `/exec`）。
6. 打開 `js/courses.js`，把網址貼到 `apiUrl: ""` 的引號裡，上傳到 GitHub。
7. 打開 teacher.html，用 `TEACHER_KEY` 登入即可。

之後修改 Code.gs，要「部署 → 管理部署作業 → 編輯 → 版本：新版本」才會生效，網址不變。

### 資料去哪裡
- 「事件紀錄」：每一筆任務回報、魔王擊破（時間、班級、座號、暱稱、項目、XP）
- 「學生名冊」：每位學生的暱稱、造型、寵物、首次登入、最後活動
- 同一個任務重複回報只會記一次；網路斷線時回報會暫存在學生裝置，下次開網站自動補送。

## 畫面
主城為全畫面地圖：地圖填滿視窗、可拖曳平移，UI 以漂浮元件疊在地圖上。右下角角色可點開狀態面板；左下角為音樂開關與全螢幕。
